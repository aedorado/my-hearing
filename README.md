# 🎧 My Hearing — Personal Sadhana & Katha Catalogue

A fast, elegant, distraction-free personal hearing catalogue and sadhana tracking portal built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**. Designed for effortless deployment on **Vercel** with client-side sadhana persistence.

---

## 🌟 Features & Highlights

- **9 Canonical Speakers (Strict Alphabetical Roster)**:
  1. **Amarendra Das** (204 lectures)
  2. **Balaram Shakti Das** (633 lectures)
  3. **Bhurijana Das** (1,882 audio lectures)
  4. **Hari Parshad Das** (675 lectures)
  5. **Indradyumna Swami** (413 lectures)
  6. **Madhavananda Das** (426 lectures)
  7. **Radha Govinda Das Goswami** (1,842 audio lectures)
  8. **Radhika Raman Das** (176 lectures)
  9. **Sacinandana Swami** (7,011 audio lectures)
  - **Total Catalog**: **13,262 lectures**
- **Unified Media Player**:
  - Seamlessly streams both **YouTube videos/audio** and direct **HTML5 MP3 audio** (from ISKCON Desire Tree and Saranagati Library).
  - Floating bottom player with scrub timeline, 10s forward/rewind, speed control (`0.75x` – `2.0x`), and volume slider.
  - Optional expandable video drawer to watch YouTube videos in PIP mode.
- **Sadhana & Hearing Tracking**:
  - Zero-login, client-side persistence in `localStorage`.
  - Mark talks as **Heard** (green badge).
  - Bookmark favorite talks with **Starred** (amber star).
  - **Continue Hearing**: Automatically saves timestamps and shows a quick-resume hero card for the last played talk.
  - **Data Backup & Restore**: One-click JSON export and import to synchronize sadhana progress across devices.
- **High Performance & Instant Filtering**:
  - Client-side fuzzy search across title, speaker, category, and verse references.
  - Filter pills: All, Unheard, Heard, Starred, YouTube only, Audio MP3 only.
  - Dynamic category dropdowns per speaker.
  - Smooth batch rendering (36 per batch) for 60fps scrolling across 12,000+ lectures.
- **Devotional Design Aesthetics**:
  - **Light Mode (Default)**: Warm parchment/ivory background with terracotta/saffron highlights.
  - **Dark Mode**: Deep slate background with warm saffron/amber accents.

## 🚀 Quickstart & Local Setup

```bash
# 1. Install dependencies
npm install

# 2. Run Next.js development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ How to Onboard New Lectures & Playlists

The repository includes idempotent automation scripts with automatic deduplication.

### 1. Onboarding a YouTube Playlist or Channel
```bash
python3 scripts/onboard_youtube.py \
  --url "https://www.youtube.com/playlist?list=..." \
  --speaker "Amarendra Das" \
  --category "Bhagavad Gita As It Is"
```
*Note: If `--category` is omitted, the playlist title on YouTube is used automatically.*

### 2. Updating ISKCON Desire Tree or Saranagati Library
```bash
# Re-crawl ISKCON Desire Tree
python3 scripts/onboard_idt.py

# Re-crawl Saranagati Library
python3 scripts/onboard_saranagati.py
```

### 3. Rebuilding the Master Catalog
Whenever any speaker dataset is updated or added:
```bash
python3 scripts/build_catalog.py
```
This merges, sorts, validates, and mirrors all data to `public/data/` for the web app.

## ☁️ Deployment on Vercel

This repository is ready for zero-friction Vercel deployment:

1. Push this repository to GitHub/GitLab.
2. Import the project into your Vercel Dashboard.
3. Framework Preset: **Next.js** (detected automatically).
4. Build Command: `npm run build`.
5. Click **Deploy**.
